# Acta 1.16.1 — Marca y búsqueda web de órdenes

Fecha: 28 de octubre de 2026

## Resultado

La versión **1.16.1** quedó cerrada como parche de identidad y portal:

- Logo oficial integrado en login, barra lateral y 404.
- Símbolo sin texto como icono del instalador, ventana y favicon.
- Búsqueda web de órdenes simplificada: número de OT solo con dígitos y clave de seguimiento.
- La búsqueda sigue exigiendo número + clave por seguridad.

**Aceptación 1.16.1: 6/6.** Smoke empaquetado 1.16.1: **6/6**. Regresión 1.16.0: **36/36** (dev y empaquetada). Regresión 1.15.0: **44/44**. Web local: **39/39**. Web remota: **7/7**.

No hay migración de base de datos.

## Entregado

### Marca

- Logo completo transparente en login móvil y 404.
- Símbolo + wordmark “BitacoreTech” en sidebar y login de escritorio.
- “Tech” en color brand y subtítulo “Taller & POS”.
- Icono del instalador 512×512 solo con el símbolo, fondo transparente.
- Favicon 256×256.
- `index.html` actualizado al nuevo favicon.
- Versión visible de la app actualizada a 1.16.1.

### Búsqueda web

- El campo de número acepta solo dígitos: `002332`.
- Si el cliente pega `#OT-002332`, el campo lo reduce a `002332`.
- El backend normaliza el número a `OT-002332`.
- La clave acepta minúsculas, espacios y el formato sin `SG-`.
- El enlace directo `/seguimiento/[code]` normaliza la clave.
- Se mantiene la validación por hash SHA-256.
- La consulta solo responde con número + clave correctos.
- Textos y ayudas del portal actualizados.
- Pruebas web actualizadas para número sin `#OT-` y clave en minúsculas.
