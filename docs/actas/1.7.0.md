- Captura opcional de usuario y contraseña/PIN/patrón en la recepción de OT.

- Auditoría de cada consulta sin guardar el secreto.

- Borrado automático al entregar y al cerrar como no reparado.
- Borrado de credenciales al restaurar un respaldo.
- Credenciales ausentes de comprobantes, PDF y mensajes.
- Editor de mensajes de ingreso y entrega en Configuración → Mensajes.
- Reportes PDF A4 inicial y de entrega.
- Apertura de WhatsApp con el mensaje renderizado y revelación del PDF en la carpeta.
- Corrección del saldo en entregas sin cobro.

## Observaciones

- WhatsApp Web no permite adjuntar archivos automáticamente; el PDF se deja revelado en la carpeta para arrastrarlo al chat.
- Si el cliente no tiene teléfono, el PDF se genera y se revela sin abrir WhatsApp.
- La restauración de un respaldo descarta las credenciales cifradas para evitar dependencia del equipo de Windows de origen.
- Los reportes se generan localmente y no se envían a ningún servicio externo.
