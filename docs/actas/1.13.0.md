# Acta 1.13.0 — Catálogo remoto con Supabase y Vercel

Fecha: 28 de octubre de 2026

## Resultado

La app publica el catálogo en **Supabase Storage** y la web de Next.js lo lee desde el bucket `catalogo-web` con revalidación. La sincronización es unidireccional: la app escribe, la web solo lee.

**Aceptación 1.13.0: 30/30 OK.** Web remota: **7/7**. Web local: **37/37**. Regresiones 1.12, 1.11 y 1.10.3 sin fallos.

## Entregado

### App

- Configuración de Supabase en **Configuración → Catálogo web**:
  - URL del proyecto.
  - bucket.
  - clave secreta cifrada con `safeStorage`.
  - activar/desactivar Supabase como destino.
  - probar conexión.
  - publicar en Supabase.
  - estado remoto: fecha, productos, imágenes, promociones, tamaño y error.
- Publicación de:
  - `catalog.json`.
  - `orders-demo.json`.
  - imágenes en `products/`.
- URLs absolutas de imagen con `?v=<hash>` para invalidar caché.
- Limpieza de imágenes remotas huérfanas.
- La clave no se devuelve en `settings.get` ni en `catalog.status`.
- La clave pública se rechaza para escritura.
- Permisos: solo propietario y administradores con `publishCatalog`.
- Auditoría de configuración, guardado/borrado de clave, prueba de conexión y publicación.
- Avisos in-app para errores de publicación local y remota.
- El respaldo local y la publicación automática opcional se mantienen.
- Sin migración nueva: el esquema sigue en **14**.

### Web

- `CATALOG_URL` para leer el `catalog.json` remoto.
- `ORDERS_URL` opcional; si falta, se deriva desde `CATALOG_URL`.
- Fallback al snapshot local si el remoto falla.
- ISR de 60 segundos (`CATALOG_REVALIDATE_SECONDS` ajustable).
- Fichas nuevas con `dynamicParams`.
- Imágenes remotas desde Supabase.
- Etiqueta “Más vendido” con la regla de 30 días y mínimo 2 unidades.
- Despliegue en Vercel: `https://bitacore-tech-app.vercel.app`.

### Más vendidos

- Query sobre `invoice_items.product_id` e `invoices.created_at`.
- Ventas activas de los últimos 30 días.
- Mínimo 2 unidades.
- El snapshot incluye `bestSellers` y `bestSeller`.
- La etiqueta solo aparece cuando hay datos suficientes.
- Las facturas antiguas sin `product_id` no cuentan; el ranking empezará a llenarse con ventas nuevas.
