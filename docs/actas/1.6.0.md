# Acta 1.6.0 — Diccionarios y ficha técnica

Fecha: 26 de octubre de 2026

## Entregado

- Módulo **Configuración → Diccionarios** con CRUD, jerarquía, orden y activación.
- Diccionarios para tipos de equipo, sistemas operativos, CPU, GPU, RAM, almacenamiento, inventario, proveedores y servicios.
- Permiso `manageDictionaries` para admin y propietario.
- Ficha técnica estructurada con CPU, GPU, RAM y almacenamiento repetibles.
- Compatibilidad y visualización de fichas planas anteriores.
- Ficha impresa en A4 y visible en el detalle de la OT.
- Categorías y ubicaciones de inventario desde diccionario.
- Categorías de proveedor desde diccionario.
- Productos marcables como servicio con tipo de servicio del diccionario.
- Versión visible de términos retirada de la recepción.

## Observaciones

- Los diccionarios del sistema no se eliminan; se desactivan o renombran.
- Renombrar una categoría de inventario, ubicación, categoría de proveedor o tipo de servicio actualiza las referencias existentes.
- El stock de un servicio no se controla; los servicios se venden sin descontar inventario.
- Las fichas antiguas se muestran como “ficha anterior” para que el taller pueda transcribirlas sin perder información.
- Los reportes de diagnóstico y las credenciales cifradas quedan para la siguiente entrega.
