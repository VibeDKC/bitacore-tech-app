# Acta 1.16.2 — Acceso inicial y actualización

Fecha: 28 de octubre de 2026

## Resultado

La versión **1.16.2** quedó cerrada como parche de acceso y actualización:

- Una base existente con administradores ya no vuelve a pedir “Configura tu taller”.
- El propietario puede iniciar sesión antes de crear el administrador.
- Botón **“¿Ya tienes una cuenta? Inicia sesión”** en primer arranque.
- Login limpio: sin OT activas, nombres del equipo, descripción de acceso protegido ni pie de instalación local.
- “¿Olvidaste tu clave?” con instrucciones y contacto por WhatsApp del taller.

**Aceptación 1.16.2: 16/16.** Smoke empaquetado 1.16.2: **16/16**. Regresión 1.16.1: **6/6** (dev y empaquetada). Regresión 1.16.0: **36/36**. Regresión 1.15.0: **44/44**.

No hay migración de base de datos.

## Entregado

### Actualización

- La configuración inicial ya no depende solo de la marca `setup_completed`.
- Si existe un administrador, la app abre en login aunque falte esa marca.
- Si la base ya estaba configurada y no hay administrador, se muestra login para recuperación; no se crea una cuenta automáticamente.
- `auth.setup` se bloquea cuando ya existe administrador o la base está marcada como configurada.
- Prueba de regresión: se eliminó `setup_completed` de una base con administrador y la app abrió en login.

### Acceso del propietario

- Botón **“¿Ya tienes una cuenta? Inicia sesión”** en la pantalla de configuración.
- Formulario de login con texto de acceso del propietario y enlace para volver.
- Solo el rol `superadmin` puede iniciar sesión mientras no haya administrador activo.
- Los demás usuarios siguen bloqueados antes del setup.
- El propietario es redirigido a Configuración con un aviso para crear el administrador o restaurar un respaldo.
- La validación del login del propietario llega al backend; la prueba automatizada confirma `INVALID_CREDENTIALS` con clave incorrecta en lugar de `SETUP_REQUIRED`. La prueba con la clave privada correcta requiere el secreto del propietario y no se incluye en el repositorio.

### Login

- Se eliminó la tarjeta de OT activa y los nombres/círculos del equipo.
- Se eliminó la descripción del aviso “Acceso protegido”.
- Se eliminó el pie “Instalación local. Tus datos permanecen en este equipo”.
- Se mantiene logo, hero y tarjetas de funcionalidades.
- Versión visible actualizada a 1.16.2.

### Recuperación

- “¿Olvidaste tu clave?” abre un modal.
- Instrucción para contactar a un administrador o al propietario.
- Botón **“Escribir al taller”** por WhatsApp usando el teléfono público del negocio.
- `auth.status` expone únicamente `businessName` y `phone`; no usuarios, órdenes, auditoría ni configuración.
