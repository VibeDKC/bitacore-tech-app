## Hallazgos y acciones

| Hallazgo | Severidad | Acción |
| --- | --- | --- |
| El POS solo permitía 0/5/10 % y la OT no permitía descuento | P1 | Descuento por % o valor en POS y liquidación de OT. |
| No existía piso de costo | P0 | Bloqueo `DISCOUNT_BELOW_COST` por línea de producto. |
| No existía fidelidad por cliente | P1 | Botón Cliente fiel, tipo/valor/vigencia y aplicación automática. |
| No existía catálogo de equipos | P1 | Tabla `equipment`, vínculo con OT, historial por cliente y backfill de OT. |
| QR no existía | P2 | Etiqueta QR interna, inactiva por defecto y activable en Negocio. |
| La matriz de permisos era solo lectura | P1 | Matriz editable por rol + excepciones por usuario. |
| No había NIT/DV ni NIT extranjero | P1 | Utilidad DIAN, DV automático, solo dígitos y campo extranjero. |
| La contraseña de respaldo no existía | P0 | Contraseña cifrada con `safeStorage`, copia con auditoría, export/import AES-256-GCM. |
| El respaldo no se podía exportar/importar | P1 | Archivo `.bctbackup` cifrado con restauración y copia de seguridad previa. |
| La sesión se recordaba y quedaba en `localStorage` | P0 | Solo `sessionStorage`; se borran sesiones al cerrar. |
| El layout tenía margen y borde flotante | P2 | Layout edge-to-edge. |
| Legal y fiscal duplicaba identidad | P2 | Cláusulas y estado fiscal dentro de Negocio. |
| Los usuarios no tenían foto, documento, teléfono ni dirección | P2 | Campos opcionales + foto 256 px. |
